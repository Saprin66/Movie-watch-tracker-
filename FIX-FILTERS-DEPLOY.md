# Исправление фильтров на опубликованном сайте

В `client/src/App.jsx` исправлена гонка запросов: при открытии вкладки «Поиск» запрос популярных фильмов мог завершиться позже запроса по жанрам/годам и заменить отфильтрованные результаты. Теперь устаревшие ответы игнорируются, а загрузка популярных фильмов не запускается поверх результатов фильтрации.

Также добавлены проверки диапазона годов и понятное сообщение, если на хостинге не задан ключ TMDB.

## Важно для production / Vercel

Переменные `VITE_*` встраиваются Vite в приложение **во время сборки**, поэтому локальный `.env` не попадает автоматически на опубликованный сайт.

1. Открой настройки проекта на хостинге (если это Vercel: **Project → Settings → Environment Variables**).
2. Проверь переменную `VITE_TMDB_API_KEY` и задай ей тот же TMDB API key, который используется локально.
3. Убедись, что переменная включена для нужного окружения (Production; Preview — если проверяешь preview-деплой).
4. Запусти новый production deployment / redeploy после изменения переменной.
5. Проверь опубликованный сайт: выбери жанр или год и нажми «Подобрать».

Если после redeploy фильтры не работают, открой DevTools → Network, выбери запрос к `api.themoviedb.org/3/discover/...` и проверь статус ответа. Код ошибки TMDB теперь также выводится на странице.
