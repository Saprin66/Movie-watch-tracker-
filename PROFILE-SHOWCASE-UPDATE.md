# Обновление профиля и витрины

В этой версии:
- профиль пользователя оформлен в стиле кинопрофиля;
- витрина только отображает выбранные фильмы;
- выбор и изменение витрины находятся в «Настройки профиля → Настройки витрины»;
- список друзей в профиле раскрывается по нажатию;
- профиль друга показывает его витрину, заглушки достижений и раскрываемый список друзей;
- список витрины хранится в базе данных, чтобы отображаться и другим пользователям.

## Развёртывание

В `server/prisma/schema.prisma` добавлено поле `User.showcaseMovieIds`. Для синхронизации схемы добавлена команда `prestart: prisma db push`, которая выполняется перед запуском сервера. Убедитесь, что на Render настроена переменная `DATABASE_URL`. После отправки изменений в GitHub дождитесь успешного redeploy backend и frontend.

Проверьте: сохранение витрины, открытие своего профиля и профиля друга, раскрытие списка друзей и мобильную вёрстку.
